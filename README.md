##
Trader Performance vs Bitcoin Market Sentiment Analysis

This project analyzes the relationship between Hyperliquid trader performance and Bitcoin market sentiment 
using the provided historical trader dataset and Bitcoin Fear & Greed Index dataset.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Outputs

The outputs folder contains summary CSV files, charts, and key findings generated from the analysis.
